# Replit Agent Prompt: Add Enterprise KPI Framework to Hexaware AI Use Case Value Framework

## Context & Objective

The **Hexaware AI Use Case Value Framework** currently has a 10-lever scoring system for use case prioritization but lacks a comprehensive KPI library for value realization tracking. 

We want to add a **KPI Framework** similar to what exists in our Markel AI@Scale portal, which has:
- 11 KPI Categories
- 68 KPIs across Insurance Value Chain + AI Operations/Enterprise metrics

**Goal:** Enhance the Hexaware project to include a browsable KPI library that can be associated with use cases for value tracking.

---

## Current Architecture Assessment

Based on the codebase review, the Hexaware project has:

```
✓ metadata_config table - stores configuration as key/value pairs
✓ use_cases table - stores use cases with scoring levers
✓ valueChainComponents - simple text array in metadata_config
✗ No hierarchical KPI structure
✗ No KPI Explorer component
✗ No Process → Activity → KPI drill-down
```

---

## Implementation Plan: Option A - Lightweight KPI Library

This approach adds KPI capabilities while respecting the existing simple architecture.

### Step 2: Create KPI Explorer Component

Create a new component `client/src/components/KPIExplorer.tsx` that reads from the metadata_config and displays the KPI library.

**Component Requirements:**

1. **Category Accordion View**: List all 11 categories as expandable sections
2. **KPI Details**: Show each KPI with name, type, benchmark, monetizable flag
3. **Filtering**: Allow filtering by value stream and KPI type
4. **Search**: Text search across KPI names and descriptions
5. **Statistics Summary**: Show total categories and KPI count at top

**Component Structure:**

```typescript
// client/src/components/KPIExplorer.tsx

import { useState, useMemo } from 'react';
import { useQuery } from '@tanstack/react-query';
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card';
import { Input } from '@/components/ui/input';
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from '@/components/ui/select';
import { Badge } from '@/components/ui/badge';
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from '@/components/ui/accordion';
import { Search, Filter, TrendingUp, DollarSign } from 'lucide-react';

interface KPI {
  kpiId: string;
  kpiName: string;
  kpiType: 'financial' | 'operational' | 'strategic' | 'compliance';
  valueStream: string;
  benchmark: string;
  monetizable: boolean;
  unit: string;
  description: string;
}

interface Category {
  categoryId: string;
  categoryName: string;
  description: string;
  icon: string;
  kpis: KPI[];
}

interface KPILibrary {
  categories: Category[];
  valueStreams: { id: string; label: string; color: string }[];
  kpiTypes: { id: string; label: string; color: string }[];
}

export function KPIExplorer() {
  const [searchTerm, setSearchTerm] = useState('');
  const [selectedValueStream, setSelectedValueStream] = useState<string>('all');
  const [selectedKpiType, setSelectedKpiType] = useState<string>('all');

  // Fetch KPI library from metadata_config
  const { data: kpiLibrary, isLoading } = useQuery<KPILibrary>({
    queryKey: ['kpiLibrary'],
    queryFn: async () => {
      const response = await fetch('/api/metadata-config/kpiLibrary');
      if (!response.ok) throw new Error('Failed to fetch KPI library');
      const data = await response.json();
      return JSON.parse(data.value);
    }
  });

  // Filter and search logic
  const filteredCategories = useMemo(() => {
    if (!kpiLibrary) return [];
    
    return kpiLibrary.categories.map(category => ({
      ...category,
      kpis: category.kpis.filter(kpi => {
        const matchesSearch = searchTerm === '' || 
          kpi.kpiName.toLowerCase().includes(searchTerm.toLowerCase()) ||
          kpi.description.toLowerCase().includes(searchTerm.toLowerCase());
        
        const matchesValueStream = selectedValueStream === 'all' || 
          kpi.valueStream === selectedValueStream;
        
        const matchesKpiType = selectedKpiType === 'all' || 
          kpi.kpiType === selectedKpiType;
        
        return matchesSearch && matchesValueStream && matchesKpiType;
      })
    })).filter(category => category.kpis.length > 0);
  }, [kpiLibrary, searchTerm, selectedValueStream, selectedKpiType]);

  // Calculate totals
  const totalKpis = useMemo(() => {
    return filteredCategories.reduce((sum, cat) => sum + cat.kpis.length, 0);
  }, [filteredCategories]);

  if (isLoading) return <div>Loading KPI Library...</div>;
  if (!kpiLibrary) return <div>No KPI data available</div>;

  return (
    <div className="space-y-6">
      {/* Header with stats */}
      <div className="flex items-center justify-between">
        <div>
          <h2 className="text-2xl font-bold">AI Operations & CoE Metrics Explorer</h2>
          <p className="text-muted-foreground">
            Navigate Category → KPI to explore IT, GenAI, and organizational metrics
          </p>
        </div>
        <div className="flex gap-4">
          <Badge variant="secondary" className="text-lg px-4 py-2">
            {filteredCategories.length} Categories
          </Badge>
          <Badge variant="secondary" className="text-lg px-4 py-2">
            {totalKpis} KPIs
          </Badge>
        </div>
      </div>

      {/* Filters */}
      <Card>
        <CardContent className="pt-6">
          <div className="flex gap-4">
            <div className="flex-1">
              <div className="relative">
                <Search className="absolute left-3 top-3 h-4 w-4 text-muted-foreground" />
                <Input
                  placeholder="Search KPIs..."
                  value={searchTerm}
                  onChange={(e) => setSearchTerm(e.target.value)}
                  className="pl-10"
                />
              </div>
            </div>
            <Select value={selectedValueStream} onValueChange={setSelectedValueStream}>
              <SelectTrigger className="w-[200px]">
                <SelectValue placeholder="Value Stream" />
              </SelectTrigger>
              <SelectContent>
                <SelectItem value="all">All Value Streams</SelectItem>
                {kpiLibrary.valueStreams.map(vs => (
                  <SelectItem key={vs.id} value={vs.id}>{vs.label}</SelectItem>
                ))}
              </SelectContent>
            </Select>
            <Select value={selectedKpiType} onValueChange={setSelectedKpiType}>
              <SelectTrigger className="w-[180px]">
                <SelectValue placeholder="KPI Type" />
              </SelectTrigger>
              <SelectContent>
                <SelectItem value="all">All Types</SelectItem>
                {kpiLibrary.kpiTypes.map(type => (
                  <SelectItem key={type.id} value={type.id}>{type.label}</SelectItem>
                ))}
              </SelectContent>
            </Select>
          </div>
        </CardContent>
      </Card>

      {/* Category Accordion */}
      <Accordion type="single" collapsible className="space-y-2">
        {filteredCategories.map(category => (
          <AccordionItem key={category.categoryId} value={category.categoryId} className="border rounded-lg">
            <AccordionTrigger className="px-4 hover:no-underline">
              <div className="flex items-center justify-between w-full pr-4">
                <div className="flex items-center gap-3">
                  <div className="w-10 h-10 rounded-full bg-primary/10 flex items-center justify-center">
                    <TrendingUp className="h-5 w-5 text-primary" />
                  </div>
                  <div className="text-left">
                    <div className="font-semibold">{category.categoryName}</div>
                    <div className="text-sm text-muted-foreground">{category.description}</div>
                  </div>
                </div>
                <Badge variant="outline">{category.kpis.length} KPIs</Badge>
              </div>
            </AccordionTrigger>
            <AccordionContent className="px-4 pb-4">
              <div className="space-y-3">
                {category.kpis.map(kpi => (
                  <Card key={kpi.kpiId} className="bg-muted/30">
                    <CardContent className="pt-4">
                      <div className="flex items-start justify-between">
                        <div className="flex-1">
                          <div className="flex items-center gap-2">
                            <span className="font-medium">{kpi.kpiName}</span>
                            {kpi.monetizable && (
                              <DollarSign className="h-4 w-4 text-green-500" />
                            )}
                          </div>
                          <p className="text-sm text-muted-foreground mt-1">
                            {kpi.description}
                          </p>
                          <div className="flex gap-2 mt-2">
                            <Badge variant="outline">{kpi.kpiType}</Badge>
                            <Badge variant="secondary">{kpi.valueStream.replace('_', ' ')}</Badge>
                          </div>
                        </div>
                        <div className="text-right">
                          <div className="text-sm font-medium text-primary">
                            {kpi.benchmark}
                          </div>
                          <div className="text-xs text-muted-foreground">
                            Benchmark
                          </div>
                        </div>
                      </div>
                    </CardContent>
                  </Card>
                ))}
              </div>
            </AccordionContent>
          </AccordionItem>
        ))}
      </Accordion>
    </div>
  );
}
```

### Step 3: Add API Endpoint for KPI Library

Add an endpoint to retrieve the KPI library from metadata_config.

**In `server/routes.ts` or appropriate route file:**

```typescript
// GET /api/metadata-config/:key
app.get('/api/metadata-config/:key', async (req, res) => {
  try {
    const { key } = req.params;
    const result = await db.query(
      'SELECT value, description FROM metadata_config WHERE key = $1',
      [key]
    );
    
    if (result.rows.length === 0) {
      return res.status(404).json({ error: 'Config key not found' });
    }
    
    res.json(result.rows[0]);
  } catch (error) {
    console.error('Error fetching metadata config:', error);
    res.status(500).json({ error: 'Failed to fetch config' });
  }
});
```
