# Hexaware AI Use Case Value Framework

Strategic AI use case prioritization platform featuring comprehensive assessment, scoring, and analytics capabilities.

## Quick Start
```bash
npm run dev  # Starts application on port 5000
```

## Core Features
- **Two-Tier Portfolio Model**: Reference Library (idea pool) and Active Portfolio (committed pipeline)
- **10-Lever Scoring Framework**: Impact and effort assessment with manual override
- **Value Realization**: KPI-based ROI tracking with confidence levels
- **Capability Transition**: Staffing curves and path to self-sufficiency
- **Responsible AI Governance**: Risk assessments with actionable mitigations per NIST AI RMF
- **Target Operating Model (TOM)**: Phase-based governance gates aligned with ISO 42001
- **Executive Analytics**: Priority matrix with Business Segment performance
- **Assessment System**: Multi-questionnaire platform using Survey.js

## Tech Stack
- **Frontend**: React 18, TypeScript, Vite, TailwindCSS, shadcn/ui, Recharts
- **Backend**: Node.js 20.x, Express.js, PostgreSQL (Neon), Drizzle ORM
- **Architecture**: LEGO-style modular components (~70 active blocks)
